## Residual risks and scope

Publication is verified only for tasks-axi 0.2.5's markdown grammar and current
`show --full` output on Linux/WSL; native Windows and macOS remain unverified.
The filesystem offers no cross-process transaction spanning multiple tasks, so
an interruption can leave a prefix created; `PARTIAL_SYNC`, durable ID reporting,
full read-back, and create-only retry are the recovery mechanism. Backlog hashes
detect changes at preflight and between Factory writes, but there is no external
backlog lock. Repository registration currently keys on canonical root basename,
so differently named clones require matching explicit home registration. No
claim is made for arbitrary tasks-axi versions/backends, dispatch, completion,
CP-04, or a real Firstmate-home publication.
