## Workflow and fixtures

`docs/WORKFLOW.md` and `skills/factory/SKILL.md` now classify risk by failure
consequence:

- bounded work uses deterministic project checks and Firstmate's normal delivery;
- normal work adds targeted integration/e2e evidence before a fresh semantic review;
- critical work adds explicit trust-boundary constraints, isolated negative tests,
  independent review, and human resolution of consequential policy.

Review receives the exact task, focused diff, relevant architecture or targeted
exact-original correction, and observed evidence—not a previous worker
transcript. Findings must cite an acceptance ID, scenario, or concrete risk and
end repaired and retested, evidence-disputed, or blocked. Factory neither invokes
no-mistakes nor changes Firstmate routing or approvals.

The executable fixtures are separate:

- `test/fixtures/workflow/normal-api.ts` covers normal profile API success and
  malformed/invalid/unknown/unsupported negative behavior.
- `test/fixtures/workflow/critical-auth-isolation.ts` uses only in-memory
  `account-a`/`account-b` and disposable `fixture-token-*` strings. Negative
  checks cover missing and forged fixture credentials, cross-account
  read/update/delete concealment, unchanged state, and ignored request-supplied
  ownership on create. It contains no real account, secret, or I/O.

## P-06: ten bounded context packs

### Method

A disposable Git project was created at ignored
`.factory/state/cp06-ten-pack`. Before any output was inspected, it was fixed at
10 task contracts with `complexity: bounded`: two bounded-risk, six normal-risk,
and two critical-risk tasks. Every task had one known task-specific source,
while `PROJECT.md` and `ARCHITECTURE.md` were mandatory for all packs. Eleven
sources were indexed at CTX generation 1; the known auth source was deliberately
left unindexed to include one retrieval-gap case in the fixed sample. This makes
the observed miss a fault-injected sample result, not a claimed production
baseline.

Each pack used the implemented command and the bounded default:

```text
node dist/src/cli.js context <ID> \
  --root .factory/state/cp06-ten-pack --json
```

All 10 commands exited 0. Every result reported a 4,000-token / 16,000-byte
ceiling, generation 1, and `HYBRID_SEMANTIC`. Relevance was scored against the
predeclared task-specific source: mandatory project/architecture sources and the
one target source were relevant; other retrieved topical files were counted as
irrelevant bulk even where tangentially useful. This strict rule avoids judging
retrieval after seeing the result.
