## Normative result

The PR #8 measurement is a **failure**, not a P-06 pass. Its predeclared oracle
counted 15 of 24 topical excerpts as irrelevant, every one of 10 packs had at
least one irrelevant excerpt, and AUTH was missing from one pack. Bounded bytes
do not make irrelevant authority relevant. The original figures remain in the
runtime evidence manifest and Git history; this correction does not relabel or
hide them.

Independent exact-head review then rejected PR #9 for three additional concrete
cases: empty task-local selection widened to the CTX corpus, the worker oracle
accepted unsuccessful or partial reads, and the critical fixture disclosed a
foreign identifier during creation. The final correction adds executable
regressions for those cases without expanding CP-06's architecture.

The smallest in-scope correction uses CTX's existing repeated `--document`
filter. Factory passes the task's reviewed `context.required` paths to `ctx
pack`; when that valid selection is empty, it passes the mandatory project
`documents.required` paths rather than accidentally issuing an unrestricted
query. Those same originals are still read exactly and included with their
digests. This is source selection before retrieval, not post-retrieval deletion:
raw CTX output remains in ignored proof scratch, provenance is unchanged, and a
missing declared source still fails closed. No CTX code, parallel retrieval
system, model router, supervisor, CP-07 extension, or CP-08 application was
added.

The contract policy now makes `context.required` the narrow task-local authority
selection. Known sources that can decide an acceptance or risk condition belong
there. A worker that discovers an omission performs one targeted exact-original
read, records the corrected assumption, and adds only that durable source before
regeneration. Global constraints and exact required originals remain visible.

## P-06 diagnosis and fixed ten-pack replay

The fixture uses only local Markdown and the installed CTX `1.0.0` with verified
`BAAI/bge-small-en-v1.5`. `ctx doctor --offline` must report
`offline_ready=true` and `network_attempted=false`; status must be clean
`HYBRID_SEMANTIC` with the semantic channel active. The runner aborts otherwise.
It indexes only the fixture's deliberate authoritative Markdown.

The bad-path control invokes real CTX with the AUTH query before `docs/AUTH.md`
is indexed and without a document selection. On the recorded replay it exited
0, omitted AUTH, and returned unrelated topical `docs/DELETION.md` and
`docs/OBSERVABILITY.md`. The raw response is retained in ignored scratch. This
corroborates the user-visible PR #8 problem rather than treating small byte size
as relevance.

The one-condition counterfactual keeps every AUTH task field fixed except
`context.required`:

```text
before: [PROJECT.md, ARCHITECTURE.md]
after:  [PROJECT.md, ARCHITECTURE.md, docs/AUTH.md]
```

Before correction, the bounded pack omits the decisive original. After the one
contract change, the regenerated pack contains exact `docs/AUTH.md` with its
digest and retains all global constraints. It corrects the assumptions to:
principal-derived ownership, ignored request ownership, `401` for missing or
forged credentials, and non-disclosing/non-mutating `404` for cross-account
read/update/delete.

The fixed sample is ten bounded packs: two bounded-risk, six normal-risk, and
two critical-risk tasks. The oracle is declared in
`test/fixtures/cp06-context/oracle.json` before output inspection: global
`PROJECT.md` and `ARCHITECTURE.md` plus the task's single target source are
relevant; every other topical source is irrelevant. The replay result is:

- **10/10 packs relevant**;
- **0 irrelevant topical excerpts** and **0 packs with an irrelevant excerpt**;
- **0 missing targets**;
- every pack within its 4,000-token / 16,000-byte bounded ceiling;
- CTX generation 2 and `HYBRID_SEMANTIC` recorded per receipt;
- exact contract, target-source, pack, receipt, output, and source digests
  recorded per task.

An additional schema-valid global-only contract uses `context.required: []`.
Factory exits 0 and emits no topical digest or excerpt. A real CTX call with the
same query and explicit `PROJECT.md`/`ARCHITECTURE.md` filters is `COMPLETE`; its
actual provenance contains only those originals and their checked digests,
despite all unrelated topical originals being indexed. This preserves viable
global-only work without treating an empty set as unrestricted retrieval.

A separate document-scoped real-CTX disconfirming probe exits 0 but reports
`PARTIAL` at its deliberately constrained 1,300-token budget; successful command
execution alone is not accepted as completeness. The missing-original case then
changes AUTH to require nonexistent `docs/ABSENT.md`: Factory exits 3 with
`CONTEXT_BLOCKED` and writes no replacement pack. Thus the correction does not
claim that a source filter can recover undeclared or absent authority and does
not fabricate completeness.

## Fresh-context targeted-original correction

After deterministic checks and the real-CTX replay, a new Pi `0.85.1` process
runs with `--no-session`, `--no-context-files`, no discovered extensions or
skills, the Factory skill explicitly selected, and only the `read` tool. Its
initial handoff contains exactly the AUTH-before contract, bounded missing-AUTH
pack, and a short deterministic evidence statement—no prior transcript.

The fresh-worker handoff deliberately omits the concrete rule that
request-supplied owner fields are ignored at creation time while retaining the
already observed `401` and concealed, non-mutating `404` evidence. The worker
reports `MISSING_SOURCE`, performs exactly one read of the supplied
`docs/AUTH.md` original, performs no broad scan, recovers principal-derived
creation ownership and the ignored request-owner rule, and identifies the
missing creation-time integration evidence.

The audit correlates `tool_execution_start` and `tool_execution_end` by tool-call
ID and event order, requires `isError: false`, forbids offset/limit and all other
reads/tools, compares the returned UTF-8 bytes and SHA-256 to the tracked exact
original, and requires the final response after the completion. Deterministic
protocol tests reject omitted, failed, partial, mismatched, out-of-order, and
extra-project cases. The genuine Pi process uses a disposable HOME and agent
directory, links rather than copies the caller-authorized credential file,
verifies that file remains byte-identical, deletes the evaluation home, and
retains no raw transcript. Model wording is nondeterministic; the protocol and
source-byte oracle are not.

## P-07 finding, repair, and retest

`test/fixtures/workflow/history/finding.json` is the minimal structured reviewer
record for `P07-MALFORMED-JSON`. The retained before module throws `SyntaxError`
for malformed profile JSON. The repaired normal API returns stable
`400 invalid_json` through its normal request function.

`npm run proof:cp06:p07` executes and records this order:

1. build — expected exit 0;
2. fail-before malformed-JSON probe — expected exit 1 with uncaught
   `SyntaxError`;
3. final malformed-JSON behavior retest — expected exit 0;
4. final critical in-memory auth tests — expected exit 0.

The final behavioral fixture also proves absent/forged credentials return 401,
own-account access succeeds, cross-account read/update/delete return 404 without
mutation, request-supplied ownership is ignored, and stored ownership comes from
the principal. Identifiers are tenant-scoped: account B can create its own
`item-a` without learning that account A already uses that identifier, while
blank titles return the same `400 invalid_title` for foreign-collision and unused
identifiers and leave state unchanged. It uses only disposable literal
identities and in-memory state; there is no network, filesystem, environment,
real account, or security-sensitive credential access.

This task-level review remains ordered after deterministic checks and before the
one normal Firstmate-owned delivery pipeline. Factory neither invokes
no-mistakes nor changes its ownership boundary.

## Acceptance and residual limitations

P-06 passes for the corrected, predeclared ten-pack sample; the original PR #8
sample remains explicitly failed. P-07 passes because the structured finding,
fail-before, repair, final behavior retest, and auth retest are executable and
bound to the replayed SHA. CP-06 makes no change to Firstmate dispatch, delivery,
or no-mistakes policy.

Residual limits are explicit: this is a small Linux fixture using CTX `1.0.0`,
not a universal retrieval-quality claim; native Windows/macOS replay is
unverified; semantic model wording and ranking can vary in later CTX/model
versions and therefore fail the proof rather than being silently accepted; and
raw runtime artifacts remain intentionally ignored and must be regenerated by
an independent reviewer.
